১. মূল নিয়ম: সবকিছু Admin প্যানেল থেকে বদলানো যাবে
----------------------------------------------------------------
নিচের প্রতিটা সংখ্যা কোডে বসানো থাকবে না, Admin প্যানেলের Settings থেকে বদলানো যাবে:
  1. ১ পয়েন্টের মান (এখন ৩০ টাকা)।
  2. মেম্বার হতে কত পয়েন্ট লাগবে (এখন ৫০)।
  3. রেফারেল বোনাস (এখন ৪০০ টাকা)।
  4. রেফারেল বোনাস পেতে কতজন রেফার লাগবে (এখন ১৫ জন)।
  5. জেনারেশন কমিশনের টাকা (এখন ৩০০ টাকা)।
  6. Club-এ প্রতিটা বিক্রি থেকে কত টাকা জমা হবে।
  7. প্রতিটা র‍্যাংকের ভাগের % (জেনারেশন কমিশন আর Club দুটোর জন্যই)।
  8. র‍্যাংকের টার্গেট আর পুরস্কার।
  9. Club-এর টাকা কত দিন পরপর বণ্টন হবে।
  10. সর্বনিম্ন Withdraw আর Withdraw চার্জ (এখন ১০%)।


২. ইউজারের ধাপ
----------------------------------------------------------------
  1. Visitor: সাইট দেখবে, প্রোডাক্ট কিনতে পারবে।
  2. Customer: রেজিস্ট্রেশন করা ইউজার। কেনাকাটা করে পয়েন্ট জমাবে।
     রেফার করতে পারবে, কিন্তু কোনো টাকা পাবে না।
  3. Member (L-1: New Member): ৫০ পয়েন্ট হলে Admin-এর কাছে রিকোয়েস্ট পাঠাবে।
     Admin Approve করলে Active মেম্বার হবে। শুধু মেম্বার হলেই কোনো টাকা পাবে না।
  4. Rank Holder: টার্গেট পূরণ করে Rank 1 থেকে Rank 7 পর্যন্ত উঠবে।
  5. একবার Active মেম্বার হলে সবসময় Active থাকবে। পরে কেনাকাটা করুক বা না করুক,
     তাতে কিছু বদলাবে না।

  3. একই ফোন নম্বর দিয়ে দ্বিতীয় অ্যাকাউন্ট খোলা যাবে না।
  4. প্রতিটা ইউজারের একটা আলাদা Member ID থাকবে, যেমন #127717।


৪. পয়েন্ট সিস্টেম
----------------------------------------------------------------
  1. Admin প্রোডাক্ট আপলোডের সময় প্রতিটা প্রোডাক্টে আলাদা পয়েন্ট দেবে।
  2. অর্ডার Delivered হলে তবেই পয়েন্ট যোগ হবে।
  3. Delivered হওয়ার আগে অর্ডার Cancel হলে পয়েন্ট যোগ হবে না।
  4. একবার পয়েন্ট যোগ হলে আর কাটা যাবে না।
  5. ১ পয়েন্ট = ৩০ টাকা, তাই ৫০ পয়েন্ট = ১,৫০০ টাকা। (Admin বদলাতে পারবে)
  6. ড্যাশবোর্ডে মোট পয়েন্ট আর পয়েন্টের হিস্ট্রি দেখাবে।


৫. মেম্বারশিপ
----------------------------------------------------------------
  1. ৫০ পয়েন্ট হলে "Membership Request" বাটন চালু হবে।
  2. Admin Approve বা Reject করবে।
  3. Approve হলে ইউজার L-1: New Member (Active) হবে।


৬. রেফারেল বোনাস (একবারই ৪০০ টাকা)
----------------------------------------------------------------
  1. যে কেউ রেফার করতে পারবে, কিন্তু টাকা পাবে শুধু Active মেম্বার।
  2. রেফার করা ব্যক্তিকে Active মেম্বার হতে হবে, মানে ৫০ পয়েন্ট আর্ন করে
     Admin-এর Approve পেতে হবে। তবেই সে রেফারকারীর হিসাবে গোনা হবে।
  3. সরাসরি ১৫ জন Active রেফার পূরণ হলে রেফারকারী একবারই ৪০০ টাকা পাবে।
     প্রতি রেফারে আলাদা আলাদা ৪০০ টাকা পাবে না।
  4. টাকা সরাসরি Wallet-এ যোগ হবে।
  5. ৪০০ টাকা আর ১৫ জন, দুটোই Admin বদলাতে পারবে।

  উদাহরণ: রহিম Active মেম্বার। সে একে একে ১৫ জনকে রেফার করল, আর ১৫ জনই
  Active মেম্বার হলো। ১৫ নম্বর জন Active হওয়ার সাথে সাথে রহিম একবার ৪০০ টাকা পাবে।


৭. জেনারেশন কমিশন (৩০০ টাকা)
----------------------------------------------------------------
  1. কেউ ৪০০ টাকার রেফারেল বোনাস পেলে, একই সময়ে ৩০০ টাকা তার জেনারেশনের মধ্যে
     ভাগ হবে। জেনারেশন মানে তার উপরের লাইনের মেম্বাররা।
  2. ৩০০ টাকা নির্দিষ্ট নয়, Admin যত টাকা সেট করবে তত টাকাই ভাগ হবে।
  3. ভাগ হবে র‍্যাংকের % অনুযায়ী (৮ নম্বর অংশের টেবিল):
     Rank 1: ৩০%, Rank 2: ২০%, Rank 3: ১৫%, Rank 4: ১২%, Rank 5: ১০%,
     Rank 6: ৮%, Rank 7: ৫%।
  4. জেনারেশনে একই র‍্যাংকের একাধিক জন থাকলে সেই র‍্যাংকের ভাগ তাদের মধ্যে
     সমান ভাগ হবে।
  5. জেনারেশনে কোনো র‍্যাংকের কেউ না থাকলে সেই ভাগ কোম্পানির কাছে যাবে।

  উদাহরণ: রহিম ৪০০ টাকা পেল। রহিমের উপরের লাইনে আছে ২ জন Rank 1 আর
  ১ জন Rank 2 মেম্বার।
     - Rank 1-এর ভাগ: ৩০০ × ৩০% = ৯০ টাকা, ২ জনে ৪৫ টাকা করে।
     - Rank 2-এর ভাগ: ৩০০ × ২০% = ৬০ টাকা, ১ জন পাবে পুরো ৬০ টাকা।
     - Rank 3 থেকে 7-এ কেউ নেই, তাই বাকি ১৫০ টাকা পাবে কোম্পানি।

  মোট বণ্টন: ৪০০ টাকা (রেফারকারী) + ৩০০ টাকা (জেনারেশন) = ৭০০ টাকা।

১০. G-Tree (জেনারেশন ট্রি)
----------------------------------------------------------------
  1. প্রতিটা মেম্বার নিজের নিচের পুরো টিম একটা গাছের (Tree) মতো ছবিতে দেখতে পারবে।
  2. প্রতিটা মেম্বারের জন্য একটা কার্ড থাকবে। কার্ডে দেখাবে:
     - নাম
     - Member ID (যেমন #127717)
     - র‍্যাংক বা পদবি (যেমন New Member, Dream Associate)
     - প্রতিটা লিংকের অবস্থা: Filled (লোক আছে) নাকি Open (খালি)
  3. কার্ডগুলো দাগ দিয়ে জোড়া থাকবে, প্রতিটা লিংকের দাগ আলাদা রঙের হবে।
  4. Active মেম্বার আর সাধারণ Customer-এর কার্ড আলাদা রঙে দেখাবে।
  5. উপরে একটা সার্চ বক্স থাকবে, যেখানে নাম বা Member ID দিয়ে টিমের কাউকে খোঁজা
     যাবে। কতজন পাওয়া গেল তা দেখাবে (যেমন 0/7), আর পাওয়া কার্ডে সরাসরি
     চলে যাবে।
  6. Tree টেনে সরানো (Pan) আর বড়-ছোট (Zoom) করা যাবে। মোবাইলেও ঠিকমতো চলবে।
  7. কোনো কার্ডে ক্লিক করলে সেই মেম্বারের নিচের টিম খুলবে।
  8. পেছনে যাওয়ার বাটন থাকবে, যাতে আগের লেভেলে ফেরা যায়।
  9. Admin যেকোনো মেম্বারের G-Tree দেখতে পারবে।

----------------------------------------------------------------
